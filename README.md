# SPENDWISE – PERSONAL EXPENSE TRACKER

**Name:** Poorvi M. S.  
**Batch:** Artificial intelligence September B

SpendWise is a personal expense tracking application developed using Python Flask, HTML, and CSS. It helps users manage their daily expenses in a simple and organized way.

The application provides a dashboard to view spending summaries and category-wise expense breakdowns. Users can add new expenses, view existing transactions, and delete expense entries. It also includes input validation to help ensure that expense details are entered correctly.

The user interface features a sidebar, a dashboard layout, and a clean design with navy blue and mint accents. The application stores expense entries temporarily in memory, so the data resets when the application is restarted.

SpendWise provides a simple and user-friendly way to record expenses, monitor spending habits, and manage personal finances more efficiently.
